Generated on 2026-07-25 12:56:23 -0700

**178** name collisions covering **356** distinct gems, out of 195399 on RubyGems.org.

These are separate gems that fold to the same name, so any tool storing one gem per file
on a case-insensitive filesystem (macOS APFS, Windows) will have them overwrite each other.

Newest release among any colliding gem: **2026-07-20** — several of these gems are still actively maintained.

## When each collision was created

Dated by the first release of the *second* gem in each pair, i.e. when the two names first
coexisted. RubyGems.org appears to have added case-insensitive name validation after this:
the most recent collision was created **2013-10-04**, and none since.
So this is legacy data in the index rather than an open validation hole.

All collisions are only pairs, no triples or more.(`FooBarBaz` and `foobarbaz`. No `FooBarBaz` and `foobarbaz` AND ALSO `fooBARbaz`)
